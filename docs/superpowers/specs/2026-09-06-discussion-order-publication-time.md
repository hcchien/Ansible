# Discussion order and publication time

Boards list discussions by latest non-deleted post publication, newest first,
falling back to thread creation. Edits and local sync never bump a thread.
Replies retain chronological reading order. Ties have a stable ID fallback.
Murmur/note comments and discussion replies display original publication date
and time in the reader's local timezone, separate from the author line. Missing
historical timestamps are not replaced with the current time.

## Constitution Review

This changes chronological presentation only, using already accessible content
metadata. No new identity claims, data collection, external requests, trust,
moderation or publication permissions are introduced. Private-board data stays
within its existing access boundary. Ranking is explicitly latest publication,
not sync/edit activity. No credentials or personhood bindings are involved;
existing exit, deletion and host selection remain unchanged. The repository's
known custody and external-host compliance gaps remain outside this change.
